# 面杀法官助手

仅供线下狼人杀法官使用的微信小程序。无需注册、登录或让玩家扫码，数据仅保存在本机微信缓存中。

## 第一版功能

- 选择板子（当前实现 12 人标准场）
- 按座位录入身份并校验数量
- 夜间固定流程提词，角色出局后也不跳过对应旁白
- 记录刀口、查验、解药和毒药
- 白天记录放逐、自曝、猎人开枪等事件
- 自动判断屠民、屠神或狼人全部出局
- 保存本局日志，退出页面后可继续

## 打开方式

在微信开发者工具中选择“导入项目”，目录选中本文件夹。未配置正式 AppID 时可使用测试号运行。

## 资料与扩展

原始规则资料位于 `docs/`。板子配置集中在 `data/boards.js`，增加板子时添加配置即可；角色资料在 `data/roles.js`。
