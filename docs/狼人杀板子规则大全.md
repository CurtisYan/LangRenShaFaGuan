# 狼人杀板子规则大全

## 一、12人标准场

### 板子配置

| 身份 | 数量 |
| --- | ---: |
| 狼人 | 4 |
| 平民 | 4 |
| 预言家 | 1 |
| 女巫 | 1 |
| 猎人 | 1 |
| 愚者 | 1 |

游戏人数：12人。本局规则：**暗牌、有警长、双曝吞警徽**。

### 胜负条件

- 所有平民出局，或所有神职出局，狼人阵营获胜。
- 所有狼人出局，好人阵营获胜。
- 白天公布出局信息后若同时满足双方条件，按“爪击在先”判定狼人获胜。

### 女巫、猎人与愚者

- 女巫全程不能自救，每晚只能使用解药或毒药中的一瓶；解药用过后，后续夜晚不再看到刀口。
- 猎人出局时可以猎捕一名玩家；被女巫毒死不能发动猎捕。
- 愚者被放逐时翻牌但不真正出局，之后不能投票、被投票或接警徽。

### 狼人、自曝与警徽

- 狼人每晚共同选择一名玩家作为袭击目标。
- 玩家出局后不亮出身份牌。
- 本板采用“双曝吞警徽”：第一次警上自曝保留竞选状态并入夜，第二次符合条件的自曝才使警徽流失。

### 出局技能连锁

猎人发动技能带走具有出局技能的角色时，后者仍按其角色规则结算；等待所有出局技能结算完毕后，再按板子规定安排出局发言。

## 二、12人白狼王守卫场

### 板子配置

  身份       数量
  -------- ------
  狼人          3
  白狼王        1
  平民          4
  预言家        1
  女巫          1
  猎人          1
  守卫          1

游戏人数：12人。

本局规则：**暗牌、有警长、双曝吞警徽**。

### 胜负条件

### 狼人阵营

满足以下任一条件，狼人胜利：

1.  所有平民出局；
2.  所有神职出局。

### 好人阵营

所有狼人出局，好人胜利。

### 爪击在先

如果白天公布出局信息后，同时满足好人与狼人的胜利条件，视为**狼人获胜**。该规则称为"爪击在先"。

### 暗牌规则

玩家出局后不会亮出身份牌。

### 女巫相关规则

1.  本板女巫**全程不能自救**。
2.  女巫每晚只能使用毒药或解药中的一瓶，不能同夜同时使用两瓶药。
3.  女巫使用解药后，之后无法再看到狼人当夜选中的出局信息。
4.  猎人被女巫毒死时，无法发动猎捕技能。

### 守卫规则

1. 守卫每晚可以守护一名玩家，防止其被狼人夜间袭击。
2. 守卫不能连续两晚守护同一名玩家。
3. 守卫的守护只对狼人的夜间袭击有效，对女巫毒药无效。
4. 若玩家被白狼王爪击后，女巫同时使用解药且守卫同时守护该玩家，会因“同守同救”而出局。

### 白狼王规则

白狼王属于狼人阵营。白狼王可以在白天自曝身份并发动技能，选择一名玩家使其一并出局。

- 白狼王自曝发动技能后没有出局发言，被技能带走的玩家也没有出局发言。
- 猎人被白狼王自曝带走时，可以继续发动猎人技能。
- 白狼王在警上自曝时，按“双曝吞警徽”规则：警徽流失，公布昨夜出局信息后天黑。
- 若白狼王与另一名玩家同时在警上，白狼王自曝并发动技能带走该玩家，流程为警徽流失、公布昨夜出局信息，然后天黑。
- 白狼王被女巫毒死时不能发动技能；非狼人玩家视角无法仅凭出局信息区分白狼王与普通狼人。

### 狼人夜间击杀

狼人每晚共同选择一名玩家作为出局目标。

当狼人对夜间出局目标意见不统一时，不同模式可能存在不同处理方式：

-   大部分模式：爪击落空；
-   部分特殊模式：从击杀票数相同的目标中随机选择一人成为出局目标；
-   部分特殊模式：狼人必须统一意见才能成功选中目标。

### 狼人自曝

狼人自曝可以立即打断当前玩家正在进行的发言，跳过当天白天接下来的剩余流程，公布出局信息后立即进入天黑。

若在警长竞选阶段按照普通自曝规则自曝，可能导致本局没有警长，这种操作称为"吞警徽"。

除狼人外，部分狼人阵营角色也可以自曝身份，具体以对应角色技能描述为准。

### 可自曝阶段

普通规则下，狼人可在以下阶段自曝：

-   警上发言阶段；
-   白天放逐发言阶段，包括平票对决产生的发言阶段；
-   采用"双曝吞警徽"规则时的退水阶段。

### 首夜吃毒后的自曝

在非"双曝"规则下，首夜吃毒的狼人警长竞选时仍可以自曝。

但自曝后不会直接进入天黑，而是进入白天放逐发言阶段。

### 双曝吞警徽

本局采用**双曝吞警徽**规则。

### 第一次自曝

警长竞选阶段有狼人第一次自曝：

1.  不会导致警徽立即流失；
2.  保留警长竞选状态；
3.  直接进入天黑。

即使第一次自曝的是首夜已经吃毒的狼人，也按此规则处理。

### 第二次自曝

夜晚正常行动后，第二天再次有狼人自曝：

1.  警徽流失；
2.  随后进入天黑。

因此，双曝吞警徽需要两次符合条件的狼人自曝完成。

### 第二天无人自曝

如果第一次自曝后的第二天没有狼人继续自曝：

1.  退水环节正常结束；
2.  进入警上投票环节；
3.  正常选出警长。

### 警上平票后的自曝

若警上投票产生平票：

1.  平票玩家轮流发言；
2.  随后再进行一轮投票；
3.  如果平票发言阶段再次有狼人自曝，则警徽流失并进入天黑。

同样可以完成"吞警徽"。

### 猎人连锁技能与出局发言

如果猎人发动技能带走具有出局技能的角色（例如狼王），被带走的角色可按其技能规则继续发动技能。

出局发言顺序根据出局产生方式处理：

-   夜间多人及技能连锁出局：等待所有出局技能结算完毕后，按游戏规定的座位顺序进行出局发言；
-   猎人或狼王被放逐投票出局并发动技能时，被其技能带走的玩家，其出局发言紧跟在猎人或狼王之后；
-   若技能源角色本身不能发表出局发言，其后续技能所带走的玩家也可能无法发表出局发言。

### 板子速记

**3狼人 + 白狼王 + 4平民 + 预言家 + 女巫 + 猎人 + 守卫**

核心规则：

-   屠边：屠民或屠神，狼人胜；
-   暗牌：出局不亮身份；
-   有警长；
-   女巫全程不能自救；
-   猎人吃毒不能开枪；
-   守卫不能连续守护同一目标；同守同救时目标死亡；
-   白狼王可白天自曝并爪击；自曝与被带走者均无出局发言；吃毒不能发动；
-   爪击在先；
-   双曝吞警徽：第一次警上自曝保留竞选状态并入夜，第二次符合条件的自曝才使警徽流失。
