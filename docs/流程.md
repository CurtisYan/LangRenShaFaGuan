# 流程

## 发牌方式

1. 每局游戏只有一套夜间流程。两种入口只决定号码身份在什么时候确认，不产生“普通夜间”和“迷糊法官夜间”两套模式。
2. **法官提前录入**：法官在身份配置页提前确认每个号码的身份，确认完整后进入第一夜并直接执行当前板子的夜间行动表。
3. **迷糊法官入口**：适用于实体身份牌已经随机发给玩家、法官开局尚不知道各号码身份的情况。法官直接进入第一夜，按照当前板子的夜间序列交替完成“确认当前身份号码—立即执行当前身份行动—进入下一张身份牌”，不先登记完整套身份再重新执行一次夜间行动表。
4. 第一夜确认身份时，所有玩家保持闭眼。页面在每项行动前提示相应身份睁眼，法官先在仅自己可见的号码区确认该身份；若该身份拥有当前夜间行动，则确认后紧接着操作。号码不得写入需要向全场念出的主持词。主持词统一使用“狼人请睁眼”“预言家请睁眼”“女巫请睁眼”等自然表述，不使用“请某身份玩家睁眼”。
5. 每种身份必须按板子规定人数完成确认，同一号码不能对应多个身份。没有主动夜间技能的神职或其他特殊身份在序列需要补齐身份信息时只进行确认，不显示行动；平民不需要睁眼确认，所有狼人、神职与其他特殊身份确认后，系统将剩余号码自动补齐为平民。若某项技能必须立即获知目标的身份或阵营，系统会在该项行动前先补齐除平民外所需的剩余身份信息，再继续该项行动。
6. 全部身份及第一夜行动确认完成前不能结算第一夜，也不能进入白天。角色规则允许放弃技能时，行动卡必须保留“本夜不发动”选项。

## 夜晚流程

1. 每个板子通过夜间行动序列配置出场顺序。页面根据该序列生成一张连续行动表，法官从上到下依次主持；调整板子顺序不需要另写一套页面流程。
2. 常规板子由狼人首先确认同伴并选择狼刀目标。需要率先行动的前置身份仍排在狼刀前，例如魔术师、噩梦之影、孤独少女（首夜）、奇迹商人、蚀时狼妃、炼金魔女与蚀日侍女（第二夜起）。
3. 觉醒隐狼每晚先于狼刀行动。其模仿技能当晚只确定模仿身份，复制到的技能从下一夜开始使用。
4. 狼刀完成后，其他需要夜间行动的特殊狼人紧接着行动，属于狼刀后的第二顺序，例如狼美人、石像鬼、狼巫、狼鸦之爪和觉醒狼王；若板子中有多名此类角色，则按板子配置顺序依次行动。
5. 守卫、女巫、摄梦人等其余身份随后行动；预言家通常最后验人。没有预言家的板子，由对应查验身份（纯白之女或魔镜少女）完成最后一次查验。
6. 角色已经出局、未到可发动夜数、技能次数耗尽或当夜被封锁时，法官仍能看到该行动卡及不能行动的原因，但不记录目标。
7. 所有行动完成后统一结算当夜效果，再进入天亮流程。愚者、平民、猎人等没有主动夜间技能的身份不在行动表中出现。

## 上警流程

1. 进入竞选警长阶段，想要竞选警长的玩家报名参与警长竞选，这种行为又被称作“上警”，参与警长竞选的玩家被称作“警上玩家”，未参与的被称为“警下玩家”。
2. 警上玩家按顺序发言，中途可以退出竞选，这种行为又叫“退水”。
3. 警上玩家发言完毕后，警下玩家进行投票，仍在警上的玩家中得票最多的当选警长。每名警下玩家每轮只能投票一次；法官记录该玩家的投向或弃票后，该玩家不能在同一轮再次投票。
4. 如果有两位及以上的警上玩家平票，则进入平票发言阶段，平票的玩家逐个发言完毕后进行投票；若投票再次平票，则警徽流失，本局游戏没有警长。
5. 警上发言期间如果有狼人自曝身份，根据板子规则不同，分为“单曝吞警徽”和“双曝吞警徽”两种：

### 单曝吞警徽流程

1. 该狼人自曝身份后，发表 30 秒的出局发言，之后宣布警徽流失，并公布昨晚出局信息。
2. 若该狼人昨晚已经死于女巫的毒药（或由于其他原因已在夜里倒牌），则公布昨晚出局信息后进入白天放逐发言阶段；否则跳过放逐发言阶段，直接进入天黑。

### 双曝吞警徽流程

1. 第一天警上竞选时若有狼人自曝身份，则在保留上警信息的情况下公布出局信息后直接天黑，不论该玩家是否在昨晚吃毒，夜间正常行动。
2. 第二天天亮后进入退水环节，此时若再有狼人自曝身份，则警徽流失，公布出局信息后直接天黑，不论该玩家是否在昨晚吃毒。
3. 若退水环节无人自曝身份，则接下来再次进行警长竞选投票；若产生平票则警上玩家轮流发言，再次投票。若此时有狼人自曝身份，则警徽流失，公布出局信息后直接天黑，不论该玩家是否在昨晚吃毒。
4. 若由于候选人出局导致只剩下一名候选人，则该候选人立刻自动当选警长。
5. 若由于候选人出局导致没有候选人，则警徽流失，本局游戏没有警长。

> 小贴士：如果没有上警玩法，第一天公布出局信息后大家就只能乱猜；有了上警阶段就完全不同了。所以如果想要完整体验《狼人杀官方正版》的乐趣，掌握上警玩法是必须的哦。

## 警徽传承

1. 已产生警长后，警长确认出局时进入警徽去向判定；愚者作为警长被放逐翻牌时，也进入警徽去向判定。
2. 警徽只有两种处理方式：警长撕毁警徽，使本局之后没有警长；或者将警徽移交给另一名可接警徽的存活玩家，由该玩家成为新警长。
3. 已出局玩家、原警长本人以及已经翻牌的愚者不能成为警徽移交目标；若场上没有可接警徽的玩家，只能撕毁警徽。
4. 新警长继承警长的发言顺序决定权和 1.5 票权重。
5. 警长出局后，法官先完成该玩家及其连锁出局玩家的技能结算，再立即校验胜负。若已经满足胜负条件，本局直接结束，不进行警徽传承。
6. 只有胜负校验后游戏仍在继续，才由原警长选择撕毁或移交警徽；完成警徽结算后，再继续遗言与后续流程。

## 白天流程

1. 法官宣布昨晚出局情况。若出现多死情况，将按照玩家号码从小到大的顺序公布昨晚出局情况，与出局顺序无关；若没有玩家出局则法官宣布“昨晚平安夜”。
2. 出局发言结束后，若有警长，则警长安排从自己的上家开始逆序发言还是从自己的下家开始顺序发言；若无警长，则看昨天是否是平安夜：若是平安夜，则从随机玩家开始顺序发言；若不是平安夜，则从出局玩家的上家开始逆序发言。
3. 发言结束后，开始放逐投票。投票时警长视为 1.5 票，得票最高的玩家出局并发表出局发言；本轮结束时仍未记录投向的可投票玩家，统一按弃票记录。
4. 玩家出局后，若板型中存在可以在出局阶段发动技能的角色（例如狼王、猎人等），则进入询问技能是否发动的阶段。
5. 除了首夜出局的玩家有遗言，之后夜晚出局的玩家都没有遗言；白天出局的玩家，除非被特殊技能带走，正常情况下都有遗言。
6. 如果有两位及以上的玩家平票，则进入平票发言阶段，发言完毕后进行投票；若再次平票，则当日平安日，即白天无人出局。
7. 期间狼人可以自曝身份立即终止白天流程。狼人发表 30 秒出局发言后，直接进入夜晚。
8. 重复夜晚流程和天亮流程，直到游戏结束。
9. 迷雾鸦影板子比较特殊：当炼金魔女存活且未使用过法老之蛇时，白天的游戏流程将变为先进行放逐发言，后公布出局信息（与一般流程相反）。

## 流局判定

1. 当游戏流程达到 20 天，则会被判定为流局。
2. 流局后，房间不关闭。
3. 流局后，本局对局会产生对战记录，但不会产生场次计数，也不会获得奖励。

> 小贴士：一般来说夜晚是狼人的天下，好人会在夜间出局，所以好人要在白天尽量准确地识别出狼人，先狼入一步把狼人都投出去才能获胜哦！
